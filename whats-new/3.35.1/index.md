### Added

- Add HSTS response headers.
- Draft band definition for Uzbekistan 923Mhz band.
- Configurable limit for concurrent subscriptions per websocket connection to prevent resource exhaustion in the Console (default: 50).
- Configurable cap for tail parameter to reduce memory usage in the Console (default: 100 events).
- Configurable inactivity timeout for Console event subscriptions to clean up stale connections (default: 15 minutes).
