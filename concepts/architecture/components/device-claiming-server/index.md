# Device Claiming Server

> The Device Claiming Server allows users to claim devices and gateways in a secure manner.

Source: https://www.thethingsindustries.com/docs/concepts/architecture/components/device-claiming-server/


The Device Claiming Server allows users to claim devices and gateways in a secure manner.

The Device Claiming Server takes care of checking verifying ownership and transferring the device or gateway from a source to a target security domain.

For more information about claiming end devices, see [Device Claiming](https://www.thethingsindustries.com/docs/hardware/devices/concepts/device-claiming/).
