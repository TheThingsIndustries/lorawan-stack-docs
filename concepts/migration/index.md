# Migrate to The Things Stack

> Concepts specific to The Things Stack Cloud

Source: https://www.thethingsindustries.com/docs/concepts/migration/


This guide documents the process of migrating end devices and gateways to The Things Stack and between different installations of The Things Stack.

End devices can be migrated from one The Things Stack deployment to another (e.g. [from The Things Stack Sandbox to The Things Stack Cloud](https://www.thethingsindustries.com/docs/concepts/migration/migrating-between-tts-distributions/)) or from any other LoRaWAN® network (like [Chirpstack](https://www.thethingsindustries.com/docs/concepts/migration/exporting-end-devices/export-from-chirpstack/)).

Depending on how many devices you are migrating and which network you are migrating from, there are multiple migration methods you can apply. Find your specific use case in subsections below and learn how to migrate your devices to a desired The Things Stack deployment.
