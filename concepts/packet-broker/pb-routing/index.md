# Default Packet Broker Routing

> This reference contains default Packet Broker routing tables.

Source: https://www.thethingsindustries.com/docs/concepts/packet-broker/pb-routing/


This reference contains default Packet Broker routing tables.

The following table explains which Forwarder Networks and Home Networks are configured by default in The Things Stack.

To configure custom routing policies for your deployment, see the [Configure Packet Broker](https://www.thethingsindustries.com/docs/concepts/packet-broker/configure/) section.

| Forwarder Network    | Home Network         | Status      |
| -------------------- | -------------------- | ----------- |
| TTS The Things Stack Sandbox     | TTS Cloud            | Enabled     |
| TTS Cloud            | TTS The Things Stack Sandbox     | Not Enabled |
| TTS Cloud <TENANT X> | TTS Cloud <TENANT Y> | Not Enabled |
