# Adding devices with ATECC608 Secure Elements

Source: https://www.thethingsindustries.com/docs/hardware/devices/adding-devices/atecc608a/


The Things Industries and Microchip developed a security solution for LoRaWAN® that enables secure key provisioning and secure cryptographic operations using secure elements.

The Things Stack supports secure key provisioning, secure join and secure communication. It uses Microchip’s hardware secure element (ATECC608B-TNGLORA) and The Things Join Server to securely store the root keys of LoRaWAN devices. As The Things Join Server is network agnostic, end users can use any distribution of The Things Stack or any standards compliant LoRaWAN Network Server.

[Learn more about this solution](https://thethingsindustries.com/secure-elements/).

[Learn how to claim secure elements](https://www.thethingsindustries.com/docs/hardware/devices/adding-devices/atecc608a/claim/).
