# Pub/Sub

> The Pub/Sub integration allows the Application Server to publish and subscribe to topics, using The Things Stack built-in MQTT client or NATS client.

Source: https://www.thethingsindustries.com/docs/integrations/other-integrations/pubsub/


The Pub/Sub integration allows the Application Server to publish and subscribe to topics, using The Things Stack built-in [MQTT client](https://www.thethingsindustries.com/docs/integrations/other-integrations/pubsub/mqtt-client/) or [NATS client](https://www.thethingsindustries.com/docs/integrations/other-integrations/pubsub/nats-client/).

> **Warning:** This feature has been removed for Cloud deployments!
