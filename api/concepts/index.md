# Concepts

> This guide introduces important concepts required to use The Things Stack APIs.

Source: https://www.thethingsindustries.com/docs/api/concepts/


This guide introduces important concepts required to use The Things Stack APIs.

The examples in these guides use HTTP (REST) APIs but the general concepts are applicable to other APIs as well.

Additional information on using the specific APIs are indicated in the corresponding sections.


## Pages in this section

- [Authentication](https://www.thethingsindustries.com/docs/api/concepts/auth/index.md): The Things Stack supports authentication using API keys, OAuth access tokens and Session cookies.
- [Field masks](https://www.thethingsindustries.com/docs/api/concepts/fieldmasks/index.md): The Things Stack APIs use field masks (on supported APIs) to specify a subset of fields that should be returned by a reading request, or updated in a writing …
- [Pagination](https://www.thethingsindustries.com/docs/api/concepts/pagination/index.md): The Things Stack supports pagination which is used to control the amount of data returned to the client for a request.
- [Errors](https://www.thethingsindustries.com/docs/api/concepts/errors/index.md): The Things Stack APIs return rich errors and error codes to indicate failure of API requests.
- [LoRa® Gateway specific APIs](https://www.thethingsindustries.com/docs/api/concepts/lora-gateway/index.md): The Things Stack supports multiple LoRa® gateway protocols which communicate the respective APIs.
- [Troubleshooting](https://www.thethingsindustries.com/docs/api/concepts/troubleshooting/index.md): Troubleshooting API
