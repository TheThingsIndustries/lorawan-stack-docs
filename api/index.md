# API

> The Things Stack is API first by design and has rich support for various kinds of APIs. This section introduces the reader to the different types of APIs …

Source: https://www.thethingsindustries.com/docs/api/


The Things Stack is API first by design and has rich support for various kinds of APIs. This section introduces the reader to the different types of APIs supported by The Things Stack, basic concepts required to use the APIs and full reference list of all the supported APIs.

<!-- more -->

<div class="fixed-table table-api">

| Type                                                      | Description                                                                                                              |
| --------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| [HTTP (REST)](https://www.thethingsindustries.com/docs/api/reference/http/)          | The Things Stack HTTP (REST) APIs are primarily used for managing entities (ex: Devices, gateways, users, organizations etc). |
| [gRPC](https://www.thethingsindustries.com/docs/api/reference/grpc/)                 | The Things Stack backend components communicate with each other primarily using [gRPC](https://grpc.io/).                     |
| [LoRa® Gateway](https://www.thethingsindustries.com/docs/api/concepts/lora-gateway/) | APIs for LoRa® Gateways to communicate with The Things Stack.                                                                 |
| [Application Integrations](https://www.thethingsindustries.com/docs/integrations/)   | APIs to read/receive application data and send downlinks to devices.                                                     |

</div>

<br/>

The [concepts](https://www.thethingsindustries.com/docs/api/concepts/) section introduces important concepts required to use The Things Stack APIs. Make sure to read these guides before using The Things Stack APIs.

The [reference](https://www.thethingsindustries.com/docs/api/reference/) section contains references on the different APIs supported by The Things Stack.
