# Getting Started

> Learn how to quickly get started with LoRaWAN®

Source: https://www.thethingsindustries.com/docs/getting-started/


Welcome to The Things Stack documentation! The Things Stack is enterprise-grade LoRaWAN® network software that provides services and tools to securely install and manage millions of LoRaWAN devices in production.

This guide is structured in four steps.

1. [Step 1: Learn basic concepts of LoRaWAN](https://www.thethingsindustries.com/docs/getting-started/1-understand-lorawan/)
2. [Step 2: Setup prerequisites](https://www.thethingsindustries.com/docs/getting-started/2-prerequisites/)
3. [Step 3: Try the Starter Kit for LoRaWAN](https://www.thethingsindustries.com/docs/getting-started/3-try-starter-kit/)
4. [Step 4: Next steps](https://www.thethingsindustries.com/docs/getting-started/4-next-steps/)

This guide additionally contains an [FAQ](https://www.thethingsindustries.com/docs/getting-started/faq/) and a [glossary](https://www.thethingsindustries.com/docs/getting-started/glossary/) to provide quick answers to frequently asked questions and definitions of key LoRaWAN terms.

Let's get started with [Step 1](https://www.thethingsindustries.com/docs/getting-started/1-understand-lorawan/).
