Getting Started

Welcome to The Things Stack documentation! The Things Stack is enterprise-grade LoRaWAN® network software that provides services and tools to securely install and manage millions of LoRaWAN devices in production.

This guide is structured in four steps.

  1. Step 1: Learn basic concepts of LoRaWAN
  2. Step 2: Setup prerequisites
  3. Step 3: Try the Starter Kit for LoRaWAN
  4. Step 4: Next steps

This guide additionally contains an FAQ and a glossary to provide quick answers to frequently asked questions and definitions of key LoRaWAN terms.
